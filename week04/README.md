# 第四周实践：PCA 降维与 K-means 聚类

## 数据与实践内容

通过 `sklearn.datasets.load_diabetes(as_frame=True, scaled=False)` 读取 scikit-learn 内置 diabetes 数据集，无需下载外部文件。使用全部 10 个原始特征预测 `target`；PCA 和 K-means 拟合时均不使用 `target`。

实践一对比均值基线、未降维线性回归、PCA 2 维和 PCA 5 维线性回归，计算解释方差和重构误差。实践二在相同的标准化训练特征上比较 K=2、K=3 的聚类结构。

## 安装与运行

已在 Python 3.10.18 下运行验证，依赖版本见 `requirements.txt`。在仓库根目录执行：

```bash
python -m pip install -r week04/requirements.txt
python week04/main.py
```

也可在 `week04` 目录执行 `python main.py`。脚本根据自身位置保存结果，不依赖启动目录。运行会重新生成结果，并打印各项指标；使用 Agg 后端保存图片，不弹出窗口。默认设置 `OMP_NUM_THREADS=2` 避免 Windows + MKL 的小样本 K-means 内存泄漏警告，已有环境设置会保留。

## 主要文件与结果

- `main.py`：两项实践的完整代码，包含中文步骤说明。
- `requirements.txt`：固定版本依赖。
- `results/metrics.csv`：每组回归模型一行，包含 PCA 维数、训练/验证/测试 MAE 和 RMSE、`selected_pca` 标记；未选中的 PCA 测试列为空。
- `results/pca_summary.csv`：2 维、5 维累计解释方差及训练/验证重构 MSE。
- `results/rmse_comparison.png`：四组模型训练与验证 RMSE。
- `results/pca_variance.png`：1–10 维累计解释方差曲线，标出 2 维和 5 维。
- `results/cluster_metrics.csv`：两组 K-means 的 K、轮廓系数、随机种子、初始化次数和输入维数。
- `results/cluster_summary.csv`：每组样本数及原始量纲下的 `bmi`、`bp` 均值。
- `results/cluster_comparison.png`：双面板聚类图，包含组号图例及投影后的中心。

图片采用英文标签，便于在没有中文字体的环境中复现。

## 关键设置

1. 沿用第三周划分：先分出 40% 临时集，再将其平分为验证集、测试集，两次 `train_test_split` 均使用 `random_state=42`。实际为训练 265、验证 88、测试 89 条，约 60%/20%/20%。四组回归共用相同划分。
2. `StandardScaler` 只在训练集拟合，再变换三个子集。目标值保持原样。
3. PCA 2 维、5 维和用于方差曲线的 10 维 PCA 均只在标准化训练特征上拟合，设置 `svd_solver="full"`、`whiten=False`。
4. 只根据验证 RMSE 在两组 PCA 回归中选维数；完全相同时选 2 维。选择后使用已经训练好的模型评估测试集，不重新拟合。测试集只评估基线、未降维回归及选定的 PCA 回归。
5. 重构 MSE 为 `mean((X_scaled - pca.inverse_transform(Z)) ** 2)`，对全部样本及 10 列平方差取平均。比较双方都在标准化特征空间，不能与预测 `target` 的 RMSE 直接比较。
6. K-means 仅使用标准化后的 10 维训练特征，设置 `n_clusters=2/3`、`random_state=42`、`n_init=10`。轮廓系数也在这个 10 维空间按欧氏距离计算。
7. 原始训练行与 `labels_` 按位置对应，统计每组原始 `bmi`、`bp` 均值，并核对每个 K 的组内样本数总和为 265。
8. 绘图复用已经拟合的 2 维 PCA，两个面板共用相同坐标和轴范围。10 维聚类中心通过同一个 PCA 的 `transform` 投影后绘制。

## 本次结果解读

| 模型 | 验证 RMSE | 测试 RMSE |
|---|---:|---:|
| 均值基线 | 76.1614 | 76.9057 |
| 未降维线性回归 | 49.1497 | 56.9703 |
| PCA 2 维 + 线性回归 | 61.5189 | 未评估 |
| PCA 5 维 + 线性回归 | 48.9917 | 58.2081 |

验证 RMSE 更低的是 5 维，因此选择 5 维。它在验证集略好于未降维回归，但测试 RMSE 略高，说明验证集上的优势不保证在测试集上保持；不能据此再用测试集改选维数。

2 维保留约 54.88% 的输入方差，训练/验证重构 MSE 为 0.4512/0.4807；5 维保留约 83.51%，对应误差为 0.1649/0.1735。更多主成分减少了输入信息损失，本次也改善了相对于 2 维的预测，但解释方差比例本身不是预测准确率。主成分是原特征的线性组合，并非直接挑选两列或五列。

K=2 的轮廓系数为 0.2334，K=3 为 0.1862，本次按该指标 K=2 的分组更清晰。K=2 两组人数为 130、135，原始 BMI 均值约为 24.11、29.02，BP 均值约为 88.38、100.96。K=3 三组人数为 124、81、60，BMI 均值约为 24.11、30.05、27.15，BP 均值约为 88.14、104.69、95.18，形成低、中、高均值的描述性差异，但两次独立拟合不能简单理解为某组被拆分。

聚类编号只是标识，不能直接解释成正常或异常，也不代表真实疾病类别。二维图中发生重叠可能来自投影丢失信息，因为实际聚类使用全部 10 维特征。
